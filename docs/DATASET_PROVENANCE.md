## Task suitability and unresolved interpretation

This source supports an independent historical occupancy forecast experiment,
not detection, slot-image classification, masks or video. It has no compatible
camera observations to join with PKLot or CNRPark. Models trained on Birmingham
must not silently forecast availability for an unrelated image/video parking lot.

Original timestamps do not include timezone offsets. No offset was assigned.
There are irregular sampling/overnight gaps; a later sequence builder must not
pretend adjacent rows are uniformly separated in time. No rows were resampled,
imputed or invented. Some car parks lack later evaluation coverage. Entity names
may describe overlapping/aggregate parking facilities; do not pool capacities.

UCI describes Occupancy as a rate in its text, but the file has integer values
and capacities. This audit interprets it as a count and flags 385 observations
above stated capacity. Confirm the originating semantics before modelling;
retaining raw values and quarantine makes this interpretation reversible.
